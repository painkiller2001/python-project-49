# Brain Games

Набор консольных игр для прокачки логики.


## Игры:

`calc`        – калькулятор  
`even`        – проверка на четность  
`gcd`         – наибольший общий делитель  
`prime`       – простое число?  
`progression` – арифметическая прогрессия  


## Запуск:

`brain-<имя_игры>`
